# `create-verse-bot`

Experimental CLI for scaffolding a Verse Bot project. It is intentionally kept separate from the runtime packages while the project structure is stabilizing.

## Usage

```bash
npm create verse-bot@latest
# or
npx create-verse-bot
```

The wizard asks for a project name and target platforms, copies the template and installs the generated project's dependencies.

Use `--local` when developing the framework itself to reference local packages.

The CLI is not required when using the runtime packages directly.
